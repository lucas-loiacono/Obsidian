## Gemini
Un array (o arreglo) en Java es una estructura de datos básica y estática que te permite almacenar múltiples valores del **mismo tipo** bajo un único nombre de variable. Funciona como una cajonera: reservás una cantidad exacta de cajones contiguos en la memoria y accedés a cada uno a través de su número de posición.

  

Aquí tenés la radiografía completa de cómo funcionan, sus reglas y sus limitaciones.

  

## 1. Declaración e Inicialización

Existen dos maneras principales de crear un array, dependiendo de si ya conocés los datos de antemano o no.

  

**Opción A: Por tamaño (cuando no tenés los datos todavía)**

Le decís a Java exactamente cuántos espacios reservar usando la palabra `new`.



```java
// Crea un array de 5 posiciones vacías para números enteros
int[] puntajes = new int[5];

// Crea un array de 3 posiciones para objetos String
String[] nombres = new String[3];
```

**Opción B: Por valores literales (cuando ya sabés qué guardar)**

Las llaves `{}` le dicen a Java que cree el array y calcule el tamaño automáticamente contando los elementos.


```Java
int[] puntajes = {85, 90, 100}; 
String[] nombres = {"Lucas", "Camila", "Santiago"};
```

## 2. Los Valores por Defecto

Cuando usás la Opción A (`new int[5]`), la memoria no queda vacía. Para evitar que el programa colapse al intentar leer un casillero vacío, Java rellena el array automáticamente:

  

- **Números (`int`, `double`, etc.):** Se llenan con `0` o `0.0`.
    
      
    
- **Booleanos (`boolean`):** Se llenan con `false`.
    
      
    
- **Objetos (`String`, `Person`, etc.):** Se llenan con `null` (como viste en tu ejemplo anterior del `new String[3]`).
    
      
    

## 3. Las Dos Reglas Inquebrantables

1. **El tamaño es inmutable:** Una vez que un array se crea en la memoria (por ejemplo, con tamaño 5), **nunca más puede crecer ni achicarse**. Si necesitás agregar un sexto elemento, estás obligado a crear un array nuevo más grande y copiar los datos a mano (o usar un `ArrayList`, que hace esto por detrás).
    
      
    
2. **Tipado estricto:** Un array de `int` solo acepta números enteros. No podés meterle un `"Hola"` ni un `double`.
    
      
    

## 4. Acceso, Modificación y Tamaño

En Java, **los índices siempre empiezan a contar desde 0**. El último elemento siempre está en la posición `tamaño - 1`.


```Java
int[] numeros = new int[3];

// Modificar datos
numeros[0] = 10; // Primer casillero
numeros[1] = 20; // Segundo casillero
numeros[2] = 30; // Tercer casillero

// Leer datos
System.out.println(numeros[1]); // Imprime: 20

// Saber el tamaño exacto
int cantidad = numeros.length; // Devuelve 3. Ojo: no lleva paréntesis, es un atributo.
```

## 5. El error más común: OutOfBounds

Si intentás acceder a un índice que no existe, Java corta la ejecución del programa inmediatamente y lanza una excepción mortal llamada `ArrayIndexOutOfBoundsException`.


```Java
int[] numeros = new int[3]; // Índices válidos: 0, 1 y 2
numeros[3] = 40; // ❌ ERROR CRÍTICO: El casillero 3 (el cuarto espacio) no existe.
```

## 6. Arrays Multidimensionales (Matrices)

Java permite crear arrays de arrays. Lo más común son los arrays de dos dimensiones, que podés imaginar como una tabla de Excel con filas y columnas.


```Java
// Crea una matriz de 3 filas y 4 columnas
int[][] tablero = new int[3][4];

// Acceder a la fila 0, columna 1
tablero[0][1] = 5;

// Crear una matriz con datos precargados
int[][] matriz = {
    {1, 2, 3}, // Fila 0
    {4, 5, 6}, // Fila 1
    {7, 8, 9}  // Fila 2
};
```
