public class Arrays {

    public static void main(String[] args) {


        // Declaración y creación

        int[] numbers = new int[3];
        System.out.println(numbers);

  

        String[] names = {"Brais", "Moure", "mouredev"};
        System.out.println(names);

  
        // Acceso

        System.out.println(numbers[0]);
        System.out.println(names[0]);

        System.out.println((new String[3])[0]);

  /*
  El código `(new String[3])[0]` que ves adentro del `System.out.println()` es una demostración de una **instanciación anónima**. Estás creando el arreglo en la memoria "al vuelo" y accediendo a su contenido en el mismo paso, sin guardarlo en ninguna variable.

Aquí está el desglose exacto de lo que hace Java en esa sola línea:

1. **`new String[3]`**: Crea un arreglo de textos nuevo con 3 casilleros vacíos en la memoria.
    
2. **Inicialización por defecto**: Como solo reservaste el espacio pero no guardaste ningún texto adentro, Java llena los casilleros automáticamente con el valor por defecto para los objetos, que es `null`. (Si fuera un `new int[3]`, los llenaría con `0`).
    
3. **`[0]`**: Inmediatamente después de crearlo, accede a la primera posición de ese arreglo.
    
4. **Impresión**: Encuentra el `null` y se lo pasa como parámetro al `System.out.println` para que lo imprima.
    

El objetivo de ese código es mostrarte que en Java **toda expresión que dé como resultado un valor puede pasarse directamente como parámetro** de un método, sin estar obligado a declararla previamente en una variable como hiciste con `numbers` o `names`.

**Un detalle extra sobre tu código:** Vas a notar que las líneas donde hacés `System.out.println(numbers);` y `System.out.println(names);` (sin indicar la posición `[0]`) no van a imprimir "Brais" o los números. Van a imprimir códigos extraños como `[I@1b6d3586` o `[Ljava.lang.String;@4554617c`.

Esto ocurre porque los arreglos son objetos pesados. Al pasárselos completos al `println`, Java no se mete a leer su contenido, sino que imprime el **identificador de su dirección en la memoria**. Para ver el contenido real de un arreglo de un vistazo, tenés que usar una herramienta nativa de Java: `Arrays.toString(names)`.
  */
  
  
  

        // Modificación

        numbers[0] = 1;

        numbers[1] = 10;

        System.out.println(numbers[0]);

        System.out.println(numbers[1]);

  

        // numbers[3] = 2; Error

  
        System.out.println(names[2]);
        names[2] = "mouredev@gmail.com";
        System.out.println(names[2]);

  

        System.out.println(names.length);

        names[2] = null;

        System.out.println(names[2]);

        System.out.println(names.length);

  

        // numbers[2] = null; Error

  
        boolean[] booleans = new boolean[5];

        System.out.println(booleans[4]);

    }

}
