Con constructores

el constructor lo que hace es que cuando yo instancio una persona le tengo que obligar que me pase datos para sus atributos
inicializa al objeto con valores desde el momento de su creacion

se crea con

public nombre_de_la_clase(){
}




```java
public class Person {

    // Atributos

    protected String name; // es lo mismo que el public, solo se puede acceder dentro del mismo paquete o que las clases sean hijas

    private int age; // no puedo acceder afuera de la clase, tengo que crear funciones adentro de la clase para acceder o cambiar

    final private String id; // con final lo declaro como constante, por lo cual no lo voy a poder modificar nunca, con el private no lo podia modificar desde afuera de la clase y ahora con final no lo puedo modificar ni adentro

  

    // Constructor

    public Person(String name, int age, String id) {

        this.name = name; //al este atributo de la clase = al parametro que le paso

        this.setAge(age); //buena practica, se lo paso al setter para la validacion de entradas de datos

        this.id = id;

    }

  

    // Métodos

    public void sayHello() {

        System.out.println("Hola, soy " + name + ", tengo " + age + " años, y mi id es " + id + ".");

    }

  
  
  
  
  //getter y setter
  
  //le doy acceso a las variables que limite con private o protected
  

    // Getter

    public int getAge() {

        return age;

    }

  

    public String getId() {

        return id;

    }

  

    // Setter

    public void setAge(int age) {

        if (age > 0) {

            this.age = age;

        } else {

            System.out.println("Edad no válida");

        }

    }

}
```

# Modificadores de acceso 

(atributos y funciones)

## Public

Puedo acceder a la función desde cualquier parte del programa

## Private

No puedo acceder a la función desde cualquier parte del programa, solo dentro de la misma clase

## Protected

Puedo acceder adentro de la clase y de las subclases, es como public, se puede acceder dentro del mismo paquete y dentro de las clases hijas aunque estén en otro paquete
