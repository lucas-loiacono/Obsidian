public class Strings {

    public static void main(String[] args) {

  

        // Declaración

        String name = "Brais";
        var surname = new String("Moure");
  

        // Operaciones básicas

        // Longitud

        System.out.println(name.length());


        // Obtener carácter

        System.out.println(name.charAt(name.length() - 1));

  

        // Subcadena

        System.out.println(name.substring(2));

        System.out.println(name.substring(1, 3));

    

        // Mayúsculas y minúsculas

        System.out.println(name.toUpperCase());

        System.out.println(name.toLowerCase());


        System.out.println(name);

  

        // Comprobar si contiene

        System.out.println("Hola, Java".contains("Brais"));

        System.out.println("Hola, Java".toUpperCase().contains("AVA"));

  

        // Comparación

        System.out.println(name.equals("Brais"));

        System.out.println(name.equals("brais"));

        System.out.println(name.equalsIgnoreCase("brais"));

  

        // == vs. equals

  

        var a = "Brais";

        var b = "Brais";

        var c = new String("Brais");

  

        System.out.println(a == b);

        System.out.println(a == c);

        System.out.println(a.equals(c));

        System.out.println(" Hola, me llamo Brais ".trim());

  
        // Replace

        System.out.println(" Hola, me llamo Brais ".replace("Brais", "Moure"));

  
        // Format

        var age = 37;

    }

}

## Gemini

Ese razonamiento aplica perfecto para los números, pero tiene una trampa importante cuando hablamos de textos.

**Para los números (`int` vs `Integer`):** Es exactamente como decís. El `int` (`int edad = 38;`) es solo un valor crudo sin herramientas. Si lo declarás como el objeto envolvente `Integer` (`Integer edad = 38;`), Java lo convierte en un objeto real y le habilita un montón de métodos útiles (como `.toString()`), a cambio de ocupar un poco más de memoria.

**Para los textos (`String` vs `new String()`):** Acá está la excepción de Java. **El `String` siempre es un objeto y siempre tiene funciones**, sin importar cómo lo declares. Tanto la versión literal como la del `new` tienen acceso a los mismos métodos (como `.length()` o `.toUpperCase()`).

La diferencia real entre ambos está exclusivamente en **cómo se gestiona la memoria**:

- `String name = "Brais";` (Literal): Utiliza una memoria ultra-optimizada llamada _String Pool_. Si creás cien variables con el texto "Brais", Java guarda la palabra una sola vez y hace que todas las variables apunten al mismo lugar, ahorrando muchísimos recursos.
    
- `new String("Brais");` (Instanciación): Le da una orden estricta a Java para ignorar la memoria optimizada y construir un bloque de memoria nuevo, pesado e independiente.
    

Por esta razón, la regla general de diseño en Java es: con los números podés elegir qué versión usar según lo que necesites hacer, pero **con los textos usá siempre la asignación directa con comillas y evitá por completo usar `new String()`**.
